# SignalStack

A polished startup idea validation platform built with React, Tailwind CSS, GSAP, and Vite.

## Features

- Startup idea submission flow with live AI-style scoring preview
- Community voting and comment feedback loops
- Trending idea dashboard with ranked signal intensity
- Reusable product-style UI with responsive layouts and motion

## Tech

- React
- React Router
- Tailwind CSS
- GSAP
- Lucide React
- Vite

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
